# unisoc-t700-ios-14-theme
Guide, launcher assets, and customization steps to transform Unisoc-powered devices (Moto e40 base) into a complete iOS 14 / iPhone XR UI experience.
Features

* **Authentic iOS 14 Lock Screen:** Faithful lock screen layout featuring custom date placement, quick-access shortcuts (flashlight and camera), and iOS notification style.
* **Pixel-Perfect Home Screen & Dock:** Custom launcher setup replicating the iconic iOS grid, icon packs, app library folders, and bottom dock.
* **Control Center Integration:** Smooth sliding control center with iOS toggles, brightness/volume sliders, and media controls.
* **System Branding Customization:** Customized device info screen displaying genuine-looking iOS version details (**iOS 14.0** / **iPhone XR** model identifier).
* **Optimized Performance:** Built and tested to run fluidly on Unisoc hardware architecture.

---

## ⚙️ Prerequisites & Base ROM

Before applying the UI customization theme, you need a clean custom ROM base installed on your device. 

1. **Base ROM:** This setup was built and tested over a vanilla Pixel 12 custom ROM port. You can download the compatible image files from SourceForge:
   👉 [Download Vanilla Pixel ROM Base on SourceForge](https://sourceforge.net) *(Replace with your direct link)*
2. **Device:** Tested on Motorola Moto e40 (Unisoc T700).
3. **Tools Required:** ADB, Fastboot, and custom recovery (TWRP/OrangeFox) if flashing the base ROM.

---

## 📦 Installation & Setup Guide

1. **Flash Base ROM:** Follow standard flashing procedures to install the vanilla custom ROM onto your Unisoc device.
2. **Install Launcher & Theme Assets:** 
   * Download the APK packages and theme assets provided in the `assets/` folder of this repository.
   * Install the iOS launcher APK as your default system launcher.
3. **Configure UI Elements:**
   * Import the layout backup or manually configure widget placements to match the iOS home screen grid.
   * Enable accessibility services if required by the control center or status bar modules.
4. **Enjoy:** Lock your device and experience the complete iOS transformation!
